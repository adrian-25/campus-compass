# CampusIQ

College discovery and comparison platform for Indian students.

## Description

CampusIQ helps students discover and compare colleges across India. Compare 1000+ colleges by fees, placements, reviews, and more to make the right decision for your future.

## Tech Stack

- **Next.js** - React framework
- **Tailwind CSS** - Utility-first CSS framework
- **Supabase** - Backend and database
- **TypeScript** - Type safety
- **Vite** - Build tool

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   - Copy `.env.example` to `.env`
   - Add your Supabase configuration
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open (http://localhost:8080](https://campus-compass-virid.vercel.app/)) in your browser

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run test` - Run tests
